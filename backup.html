Backup & Restore (backup build: bk1)

One-click export of every table in the database to a single JSON file you keep, and a guarded restore that puts a backup file back. This is the app's safety net — take a backup before any risky change, and keep a recent one somewhere off this device.

Download a backup

Fetches every table below and saves one JSON file to this device (share it to iCloud/Files to keep it safe). Nothing is changed in the database.

Restore from a backup file

Choose a backup file, review what it contains, then confirm. Restore deletes every row in each ticked table and re-inserts the rows from the file.

Restore is destructive. Each ticked table is emptied first. Restoring bd_members cascade-deletes rows in the seven tables that reference it, so when restoring members always tick the whole set (the default). If a table's delete step reports 403/permission errors, that table is missing a Row Level Security DELETE policy in Supabase — stop and add it before retrying, otherwise rows will be duplicated.
