Read from a screenshot

Three ways in, best first:
1. Paste the screenshot itself. In Photos, tap Share → Copy Photo, then paste anywhere on this page — it will be read automatically.
2. Paste Apple’s text. In Photos, tap the Live Text button (the small square-with-lines icon in the bottom-right of the image), then Copy All, and paste into the box below. Don’t long-press the text itself — if a merchant name looks like a web address, such as Amazon.co.uk, iPadOS offers you the link menu instead of Copy All.
3. Pick the file below and press Read text from image.
Apple’s recognition is the more accurate with numbers, so route 2 is worth the extra taps when a statement matters.
